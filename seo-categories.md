# SEO des catégories de produits — EauService

> **Comment l'utiliser :**
> 1. WordPress → **Produits → Catégories** → cliquez sur une catégorie → **Modifier**.
> 2. Collez la **Description** (texte riche) dans le champ « Description » de la catégorie.
>    (Si l'éditeur n'accepte pas le HTML, passez l'onglet en mode « Texte »/HTML.)
> 3. En bas, dans le panneau **Yoast SEO**, renseignez :
>    - **Expression clé principale**
>    - **Titre SEO**
>    - **Slug** (uniquement si vous créez la catégorie ; sinon laissez l'existant)
>    - **Méta description**
> 4. Remplacez les liens `VOTRE-SITE` par vos vraies URL quand vous me les enverrez
>    (je régénérerai une version finale prête à coller).
>
> 💡 Astuce : variez les expressions clés d'une catégorie à l'autre pour ne pas
> qu'elles se "cannibalisent" entre elles dans Google.

## Mémo — réglages Yoast pour CHAQUE catégorie

1. **Expression clé principale** → celle indiquée ci-dessus (une différente par catégorie).
2. **Titre SEO** → commence par l'expression clé.
3. **Méta description** → 120–155 caractères, contient l'expression clé.
4. **Slug** → court, avec l'expression clé (tirets, sans accents).
5. La **description** collée contient déjà : l'expression clé dans le 1er paragraphe,
   dans un sous-titre (H2), plusieurs fois dans le texte, + des liens internes et un
   lien externe → voyants Yoast au vert.

> ⚠️ Les liens `VOTRE-SITE` sont des espaces réservés. Envoyez-moi votre domaine et
> vos slugs réels et je vous renvoie une version finale 100% prête à coller.
