# SEO des catégories de produits — EauService (VERSION FINALE)

> Site : https://eau-service-events.fr/
> URL des catégories : https://eau-service-events.fr/categorie-produit/{slug}/
>
> **Comment l'utiliser :**
> 1. WordPress → **Produits → Catégories** → cliquez sur une catégorie → **Modifier**.
> 2. Collez la **Description** (texte riche) dans le champ « Description » de la catégorie.
>    (Si l'éditeur n'accepte pas le HTML, basculez en mode « Texte »/HTML.)
> 3. En bas, dans le panneau **Yoast SEO**, renseignez :
>    - **Expression clé principale**
>    - **Titre SEO**
>    - **Slug**
>    - **Méta description**
> 4. Mettez à jour.
>
> ⚠️ Vérifiez que vos URL de catégories sont bien en `/categorie-produit/...`.
> Si chez vous c'est `/product-category/...`, dites-le moi et je corrige les liens.

## Mémo réglages Yoast (à répéter pour CHAQUE catégorie)

1. **Expression clé principale** → celle du tableau (une différente par catégorie).
2. **Titre SEO** → commence par l'expression clé.
3. **Méta description** → 120–155 caractères, contient l'expression clé.
4. **Slug** → déjà correct chez vous.
5. La **description** collée contient déjà : l'expression clé dans le 1er paragraphe,
   dans un sous-titre (H2), plusieurs fois dans le texte, + liens internes et lien externe
   → voyants Yoast au vert.
